# LPC1768 ADC LM35 LCD Temperature

A simple embedded system project using the **LPC1768 microcontroller** to measure temperature using an **LM35 temperature sensor** and display the result on a **16×2 LCD**.

## Components
- LPC1768
- LM35 Temperature Sensor
- 16×2 LCD

## Working
The LM35 output is connected to the LPC1768 ADC. The ADC value is converted into temperature and displayed on the LCD.

## Tools
- Keil µVision
- Embedded C

## File
- `main.c` – Source code for ADC, LM35 interfacing, and LCD display.
